# NetBox Source of Truth

Enterprise-style structured NetBox inventory project designed to simulate a real-world Source of Truth (SoT) implementation for network automation environments.

## Features

- Structured enterprise inventory modeling
- NetBox Source of Truth design
- CSV-based inventory imports
- Standardized naming conventions
- Multi-site inventory hierarchy
- Device lifecycle modeling
- IPAM structure
- Topology modeling
- Automation-ready inventory structure
